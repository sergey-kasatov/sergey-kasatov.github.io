Datenschutz.

Was diese Website verarbeitet, warum, und welche Rechte Sie haben. Kurzfassung: keine Cookies, kein seitenübergreifendes Tracking, keine eingebetteten Fremdinhalte.

Sergey Kasatov
Köln, Deutschland (Postanschrift auf Anfrage)

2. Was diese Website nicht tut

kasatov.de ist eine statische Website. Sie setzt keine Cookies, bindet keine Fremdinhalte ein (keine Videos, Karten, Social-Media-Buttons oder externen Schriften) und lädt ihre Schriften vom eigenen Server. Sie erstellt keine Profile und gibt keine Daten an Werbenetzwerke weiter. Die einzige externe Anfrage Ihres Browsers geht an den in Abschnitt 4 beschriebenen Statistikdienst.

3. Hosting und Server-Logfiles

Die Website wird über GitHub Pages ausgeliefert, einen Dienst der GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA. Beim Aufruf einer Seite erhalten die Server von GitHub die Daten, die jede Webanfrage mitführt: Ihre IP-Adresse, die aufgerufene Seite, Datum und Uhrzeit, die verweisende Seite sowie Browser und Betriebssystem. GitHub gibt an, die IP-Adressen der Besucher von GitHub-Pages-Websites zu protokollieren, um rechtlichen Pflichten nachzukommen und den Dienst abzusichern; siehe die GitHub General Privacy Statement. GitHub gibt an, für Übermittlungen in die USA am EU-U.S. Data Privacy Framework teilzunehmen.

Rechtsgrundlage: mein berechtigtes Interesse an einer sicher und zuverlässig ausgelieferten Website (Art. 6 Abs. 1 lit. f DSGVO). Über das hinaus, was GitHub bereitstellt, habe ich keinen Zugriff auf diese Protokolle.

4. Besucherstatistik (GoatCounter)

Um ungefähr zu sehen, wie viele Menschen welche Seiten lesen, nutzt diese Website GoatCounter, einen quelloffenen, datenschutzfreundlichen Statistikdienst. Beim Laden einer Seite sendet Ihr Browser eine Anfrage an gc.zgo.at mit der Seitenadresse, der verweisenden Website, Ihrer Bildschirmgröße und der User-Agent-Kennung Ihres Browsers; Land und Region werden aus der IP-Adresse abgeleitet. GoatCounter setzt keine Cookies und speichert Ihre IP-Adresse nicht; um einen Besuch nur einmal zu zählen, hält es einen kurzlebigen Hash vor, der nicht auf Sie zurückgeführt werden kann. Details: GoatCounter Privacy Policy und GoatCounter GDPR-Hinweise.

Rechtsgrundlage: mein berechtigtes Interesse daran zu wissen, ob die Website gefunden und gelesen wird (Art. 6 Abs. 1 lit. f DSGVO). Wenn Sie die Anfrage in Ihrem Browser blockieren, funktioniert die Website genauso.

5. Kontaktaufnahme per E-Mail

Wenn Sie mir schreiben, verarbeite ich die von Ihnen übermittelten Daten (E-Mail-Adresse, Name, Inhalt der Nachricht), um Ihnen zu antworten. Betrifft der Kontakt eine mögliche Anstellung oder Beauftragung, ist die Rechtsgrundlage Art. 6 Abs. 1 lit. b DSGVO (vorvertragliche Maßnahmen); andernfalls mein berechtigtes Interesse an der Beantwortung von Anfragen (Art. 6 Abs. 1 lit. f DSGVO). Ich bewahre die Korrespondenz so lange auf, wie das Gespräch es erfordert und wie ich sie zur Dokumentation benötige, und lösche sie auf Wunsch.

6. Local Storage

Wenn Sie die Website zwischen dem Papier- und dem Blaupausen-Thema umschalten, wird Ihre Wahl im Local Storage Ihres Browsers gespeichert (Schlüssel theme), damit die Seite sie beim nächsten Besuch wiederfindet. Dieser Wert verlässt Ihren Browser nicht und ist kein Cookie.

7. Externe Links

Diese Website verlinkt auf LinkedIn, GitHub, Tableau Public, Streamlit Community Cloud, Credly, Udemy, LinkedIn Learning und Analyst Builder. Beim Lesen dieser Website werden keine Daten an diese Dienste übertragen; sobald Sie einem Link folgen, gelten deren eigene Datenschutzerklärungen.
